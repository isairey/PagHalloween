# 🎃 Halloween Web

Sitio web temático de **Halloween**, diseñado para ofrecer una experiencia visual inmersiva con elementos interactivos, animaciones y contenido espeluznante 👻.

---

## 🕸️ Descripción

**Halloween Web** es una página web creada con el objetivo de celebrar el espíritu de Halloween mediante una interfaz oscura, efectos visuales llamativos y contenido dinámico.

Incluye animaciones, sonidos y elementos interactivos que mejoran la experiencia del usuario.

---

## 👻 Características

- 🎃 Diseño temático oscuro (modo Halloween)
- 🕷️ Animaciones (fantasmas, calabazas, murciélagos)
- 🔊 Efectos de sonido (opcional)
- ✨ Transiciones y efectos visuales
- 📱 Diseño responsive (móvil y escritorio)
- 🧟 Secciones interactivas (juegos, historias, etc.)

---

## 🧱 Tecnologías utilizadas

- **Frontend:** HTML, CSS, JavaScript  
- **Animaciones:** CSS Animations / JavaScript  
- **Framework (opcional):** React / Vue
